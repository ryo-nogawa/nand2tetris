## 目的

低レイヤー学習（nand2tetris）の中でClaudeに質問した不明な単語や概念の解説を、後から見返せるように `notes/` 配下のMarkdownファイルへ保存する。

## 手順

1. **対象の特定**: 直前のClaudeの解説内容を保存対象とする。引数でトピックが指定された場合はそれを優先する。会話の中で複数の解説がある場合は、ユーザーに「どの解説を保存するか」を確認する
2. **タイトルの決定**: 解説内容を表す簡潔なタイトルを日本語で決める（例: `論理ゲートとは`、`2の補数`、`フリップフロップ`）。ファイル名に使えない文字（`/ \ : * ? " < > |` や空白）は避け、空白はアンダースコアに置き換える
3. **ファイル名の生成**: `notes/<日付(yyyyMMdd)>_<タイトル>.md` 形式とする。日付は今日の日付を `date +%Y%m%d` で取得する
4. **保存先の準備**: `notes/` ディレクトリが存在しなければ作成する
5. **ファイルの書き込み**: 下記テンプレートに沿って解説内容をMarkdownで整形して保存する
6. **完了報告**: 保存したファイルのパスをユーザーに伝える

## ファイルテンプレート

```markdown
# <タイトル>

> 作成日: <yyyy-MM-dd>
> 分類: <該当する章・テーマがあれば記載（例: Project 1 論理回路）>

## 概要

<1〜2文での要点まとめ>

## 解説

<Claudeの解説内容を、見出し・箇条書き・図解（必要なら）で整理して記述>

## ポイント・補足

<理解の助けになる補足や、つまずきやすい点>

## 関連用語

<関連する用語があればリンクや箇条書きで（例: [[20260613_2の補数]]）>
```

## 注意事項

- 内容は省略せず、解説のポイントを漏らさずに記述する。ただし会話の冗長なやり取りはノート向けに整理し直す
- 初学者が後で読んで理解できるよう、専門用語にはかみ砕いた説明を添える
- 同名ファイルが既に存在する場合は、上書きせず内容を追記するか、ユーザーに確認する
- 図やコード例が解説に含まれていた場合は、Markdownのコードブロックや表を使って再現する
