# RAM（ランダムアクセスメモリ）

> 作成日: 2026-06-20
> 分類: Project 3 順序回路・メモリ

## 概要

RAM の正体は「レジスタ（記憶箱）を n 個並べたもの」であり、アドレスを指定して特定のレジスタだけを読み書きできる。どのアドレスでも、また RAM のサイズに関わらず、アクセス時間は一定で一瞬であることが最大の特徴。

## 解説

### 1. RAM は Register チップを並べたもの

- **レジスタ(Register)** = 1個の値を記憶しておける最小の記憶装置。
  - これまで作った流れ: D フリップフロップ → 1ビットレジスタ → 16ビットレジスタ（値を覚えておく箱）。
- **RAM** は、そのレジスタを n 個ズラッと並べただけのもの。

```
RAM8（レジスタ8個の例）
┌─────────────────────────┐
│ アドレス0: [ レジスタ ]  ← 16ビットの値を1個記憶  │
│ アドレス1: [ レジスタ ]                          │
│ アドレス2: [ レジスタ ]                          │
│ ...                                            │
│ アドレス7: [ レジスタ ]                          │
└─────────────────────────┘
```

→ 「メモリ」と聞くと特別な部品に思えるが、正体は記憶箱(レジスタ)の集合体にすぎない。

### 2. アドレスを指定して、対応するレジスタだけを読み書き

- レジスタが n 個あると「どの箱を使うのか」を選ぶ必要がある。その**箱の番号(背番号)が「アドレス(address)」**。
- ここで以前作った2つの部品が活躍する:
  - **Mux(マルチプレクサ)**: たくさんの入力から1つだけを選んで出力 → **読み込み**に使う
  - **DMux(デマルチプレクサ)**: 1つの入力を、指定した1つの出口だけに流す → **書き込み**に使う
- アドレスを指定すると、指定したレジスタ1個だけが読み書きの対象になり、他のレジスタには一切影響しない。

### 3. アクセスは一瞬で、アドレスやサイズに左右されない（最重要）

> どのアドレスにアクセスしても、RAM が大きくても小さくても、かかる時間は同じで、しかも一瞬。

理由: **全てのレジスタが回路として並列に(同時に)つながっている**から。

| | データ構造の探索 | RAM のアクセス |
|---|---|---|
| 仕組み | 1個ずつ順番に見ていく | 全レジスタが同時に配線済み |
| アドレス100番へ | 100回たどる | Mux/DMux が一発で選ぶ |
| かかる時間 | 場所による(遅い) | どこでも一定(一瞬) |

- アドレスを Mux/DMux に与えた瞬間、電気信号が回路を流れて目的のレジスタが選ばれる。
- 100番目だろうが0番目だろうが、電気が流れる経路は用意済みなので時間差がほぼ生じない。

## ポイント・補足

- **「ランダムアクセス」の本当の意味**: 「ランダム」は「でたらめ」ではなく、「どの場所へも(順番を無視して)即座に行ける」という意味。これが Random Access Memory の名前の由来。
- アプリ開発者の感覚だと、つい「配列やリストを先頭から順番に探す(O(n))」イメージを持ちがちだが、ハードウェアの RAM は違い、どのアドレスも O(1)（一定時間）でアクセスできる。
- この「アクセス時間が一定」という前提があるからこそ、後で作る CPU は「メモリのどこを読んでも同じコストだ」と仮定してプログラムを設計できる。とても重要な土台。
