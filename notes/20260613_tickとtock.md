# tickとtock（離散時間とクロック）

> 作成日: 2026-06-13
> 分類: Project 3 順序回路 / クロックと時間

## 概要

コンピュータは時間を「飛び飛びの区切り（離散時間）」で扱う。その1区切り（1サイクル）はクロック信号の前半 **tick** と後半 **tock** で構成され、「tickで計算し、tockで記憶へ書き込む」を繰り返して時間を1コマずつ進めていく。

## 解説

### キーワードの整理

- **離散（りさん）時間** … 時間を「連続」ではなく「飛び飛びの区切り」で扱うこと
- **シーケンス** … 順番に並んだ一連の流れ
- **tick / tock** … 時計の「カチ（tick）／コチ（tock）」という音に由来。クロックの2つの状態

### 1. 連続時間と離散時間の違い

普段感じる時間は「連続」で途切れがない。一方コンピュータは時間を「飛び飛びの区切り」で扱う。

```
連続時間 :  ─────────────────────  （途切れなく流れる）

離散時間 :  ① ─ ② ─ ③ ─ ④ ─ ⑤  （1コマ、2コマ…と区切る）
```

コンピュータにとって「時間が進む」とは、この区切りが1つ次に進むこと。パラパラ漫画のように静止画（区切り）が切り替わるイメージ。

### 2. tickとtock = 1区切りの「前半」と「後半」

コンピュータには規則正しく繰り返す **クロック** 信号があり、2つの状態を交互に行き来する。

```
   tick        tock        tick        tock
 ┌──────┐            ┌──────┐
 │      │            │      │            ←  信号の高い/低い
─┘      └────────────┘      └──────────

 └─────  1サイクル  ─────┘
```

- **tick** … クロックの前半（例: 信号がHigh=1の期間）
- **tock** … クロックの後半（例: 信号がLow=0の期間）

「tick → tock」で1セット = 1つの離散時間の区切り（1サイクル）。これを繰り返して「①②③…」と時間が刻まれる。時計の「カチ・コチ」の2拍子で1秒が刻まれるのと同じ。

### 3. なぜ2つに分けるのか（最重要）

順序回路（記憶する回路）の記憶を安全に更新するため、「考える時間」と「覚える瞬間」を分けている。

1. **tick（前半）** … 「計算」をする時間。回路の中で値が変化し、落ち着くのを待つ。記憶はまだ書き換えない。
2. **tock（後半）** … 計算が安定した結果を、記憶（レジスタ）にパチッと書き込む瞬間。

この区別がないと、計算の途中（値がバタバタ変化している最中）に記憶を書き込んでしまい、中途半端な値を覚える危険がある。tickで十分計算を落ち着かせ、tockで一斉に記憶を更新することで確実に動作する。

### 4. シミュレータでの体験

nand2tetrisのハードウェアシミュレータでは手で操作できる。

- `tick`（半サイクル進める）
- `tock`（残りの半サイクルを進めて1サイクル完了）

これを繰り返すと、順序回路が1ステップずつ動く＝離散時間が1コマずつ進む様子を観察できる。

## ポイント・補足

- 標語: **「tickで考えて、tockで覚える」** を繰り返してコンピュータは離散時間を前に進める
- この時間の刻みは特に **順序回路（Register, PC, RAM）** で意味を持つ
- **組み合わせ回路には時間の概念がない**。tick/tockを待たず即座に反応するため
- tick/tockのどちらをHigh/Lowに対応させるかは教材・文脈により表記が異なるが、「前半と後半で1サイクル」という本質は同じ
