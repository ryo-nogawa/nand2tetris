# デマルチプレクサ（DMux）

> 作成日: 2026-06-14
> 分類: Project 1 論理回路 / 選択回路

## 概要

デマルチプレクサ（DMux）は「1つの入力を、selで2つの出口のどちらかに振り分ける」部品。Muxの逆操作にあたり、Muxが「複数から1つを選ぶ（合流）」のに対し、DMuxは「1つを行き先で振り分ける（分岐）」。

## 解説

### 1. ひとことで言うと

DMux = 「1つの入力を、selで2つの出口のどちらかに振り分ける」部品。Muxとは完全に真逆の動き。

```
Mux（合流）              DMux（分岐）
a ─┐                     ┌─→ a
   ├→ out          in ──┤
b ─┘                     └─→ b
   ↑                        ↑
  sel                      sel
```

### 2. 身近なたとえ

宅配便の仕分けベルトコンベア。1本のレーンから荷物（in）が流れてきて、行き先ラベル（sel）を見て右の箱（a）か左の箱（b）かに振り分ける。
- Mux = 複数の番組から1つ選ぶリモコン
- DMux = 1つの荷物を行き先別に仕分ける装置

### 3. 動作：selで「どっちの出口に流すか」が決まる

- `sel = 0` のとき → `a = in`、`b = 0`（aの出口に流す）
- `sel = 1` のとき → `a = 0`、`b = in`（bの出口に流す）

選ばれなかった方には0を出す。

真理値表:

| in | sel | a | b |
|---|---|---|---|
| 0 | 0 | 0 | 0 |
| 1 | 0 | 1 | 0 ← selが0なのでaにinが出る |
| 0 | 1 | 0 | 0 |
| 1 | 1 | 0 | 1 ← selが1なのでbにinが出る |

- inが流れるのは選ばれた片方の出口だけ
- もう片方は必ず0
- in=0のときはどちらの出口も0（流すものがない）

### 4. Muxとの対比（理解のカギ）

| | Mux | DMux |
|---|---|---|
| 入力 | 2つ（a, b） | 1つ（in） |
| 出力 | 1つ（out） | 2つ（a, b） |
| 役割 | 複数から1つ選ぶ | 1つを行き先に振り分ける |
| イメージ | 合流・選択 | 分岐・仕分け |
| selの意味 | どの入力を通すか | どの出口に流すか |

入力と出力の数がちょうど入れ替わっている。これが「逆の操作」と言われる理由。

### 5. なぜ必要なのか

「1つのデータを状況に応じて違う場所に送りたい」場面で使う。
- 計算結果を「メモリのどのアドレスに書くか」振り分ける
- 1つの信号を「どの部品に届けるか」選んで送る

Mux（選んで集める）とDMux（振り分けて配る）はペアで、データの流れをコントロールする土台になる。

### 6. 作り方のヒント（実装計画）

AndとNotだけで作れる。各出口を「inを通すか塞ぐかの弁（And）」にする。
（前提知識: `And(in, 1)=in`（開）、`And(in, 0)=0`（閉）→ [[20260614_マルチプレクサ]] 参照）

```
a = in AND (NOT sel)    ← selが0のときだけ in を通す
b = in AND sel          ← selが1のときだけ in を通す
```

- sel=0 → NOT sel=1 → a=And(in,1)=in、b=And(in,0)=0
- sel=1 → NOT sel=0 → a=And(in,0)=0、b=And(in,1)=in

骨組み（穴埋め）:

```
    PARTS:
    Not (in=sel, out=notSel);
    And (a=in, b=notSel, out=a);
    And (a=in, b=sel, out=b);
```

Muxと使う部品はそっくり（Not + And×2）だが、配線の向きが「振り分け」になっている。Orで合流しない点に注目（出口が2つに分かれたままだから）。

## ポイント・補足

- **標語**: DMux = Muxの逆。1つの入力を、selというラベルで「どっちの出口へ流すか」仕分ける回路
- Muxは最後にOrで合流するが、DMuxは合流しない（出口が2本のまま）
- 発展形: DMux4Way（4つの出口に振り分け、sel2ビット）、DMux8Way（8つ、sel3ビット）
- Andが「弁（スイッチ）」として働く考え方はMuxと共通
