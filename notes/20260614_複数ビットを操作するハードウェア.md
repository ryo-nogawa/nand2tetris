# 複数ビットを操作するハードウェア（And16とバス）

> 作成日: 2026-06-14
> 分類: Project 1 論理回路 / 多ビット演算

## 概要

複数ビットのハードウェアとは、電線を何本も束ねた「バス」を扱う回路のこと。大きなビット幅の演算は、1ビットの基本ゲートをビットの数だけ並べることで作れる。例として `And16` は、1ビットの `And` を16個並べて「2つの16ビットデータをビットごとにAND」する。

## 解説

### 1. 1ビットと複数ビットの違い

これまでの `And` は入力が `a`, `b` の2本だけ（各1ビット）で、扱える値は0か1のみ。電線が1本のイメージ。
一方、実際のコンピュータは大きな数を扱うため、ビットを何本も並べて表現する。

```
数の「5」を4ビットで表すと →  0 1 0 1
                              └─┴─┴─┘ ビットが4個並んでいる
```

この「ビットを束ねたもの」を扱うのが複数ビットのハードウェア。

### 2. 16ビット = 電線が16本束ねられている（バス）

`And16` の `16` は「16ビット幅」。入力 `a`, `b` が16本の電線の束になっている。この束を **バス（bus）** と呼ぶ。

```
CHIP And16 {
    IN a[16], b[16];   // [16] が「16ビットの束」を意味する
    OUT out[16];
    ...
}
```

- `a[16]` … 16本ある宣言
- `a[0]` … 束の0番目の線（一番右のビット）
- `a[15]` … 束の15番目の線（一番左のビット）
- `a[3]` … `[番号]` で束の中の特定の1本を取り出せる

### 3. ビットごと（bitwise）のANDとは

「同じ位置どうしのビットをANDする」だけ。16個のペアをそれぞれ独立にANDする。

```
a:  1 0 1 1 0 0 1 0 ...（16ビット）
b:  1 1 0 1 0 1 1 0 ...（16ビット）
    ┴ ┴ ┴ ┴ ┴ ┴ ┴ ┴   ← 各位置でAND
out:1 0 0 1 0 0 1 0 ...（16ビット）
```

- 0番目: a[0]=1 AND b[0]=1 → out[0]=1
- 1番目: a[1]=0 AND b[1]=1 → out[1]=0
- 2番目: a[2]=1 AND b[2]=0 → out[2]=0

位置をまたいだ計算はしない。各ビットが完全に独立。これが「ビットごと（bitwise）」の意味。

### 4. ハードウェアとしての実装イメージ

新しい複雑な部品を作る必要はない。**すでに作った1ビットの `And` を16個並べるだけ**。

```
    PARTS:
    And (a=a[0],  b=b[0],  out=out[0]);
    And (a=a[1],  b=b[1],  out=out[1]);
    And (a=a[2],  b=b[2],  out=out[2]);
    ...（out[15]まで16行）
```

- `a[0]` で入力バスの0番目のビットを取り出し
- `And` の入力につなぎ
- 結果を出力バスの `out[0]` に入れる

これを[0]〜[15]まで16行書けば完成。
→ 「部品を組み合わせて、より大きな部品を作る」という設計思想がはっきり現れている。

### 5. なぜ必要か

コンピュータが扱うデータ（数値・文字・命令）はほとんどが16ビットや32ビットといったまとまった単位。1ビットずつしか処理できないと非効率なので、16個のAndを並べて一度に16ビット分を処理する。後の章の `ALU`（計算の中枢）も、こうした16ビット幅の演算部品を組み合わせて作られる。

## ポイント・補足

- **標語**: 大きなビット幅の演算 = 小さな1ビット演算を、ビットの数だけ並べたもの
- `[16]` は「16本束ねる」宣言、`[3]` は「束から1本取り出す」アクセス、という違いに注意
- ビットごと演算では桁の繰り上がり等は起きない（位置をまたがない）。繰り上がりが関わる加算（Adder）はまた別の仕組み
- 同じ発想で `Or16`, `Not16`, `Mux16` なども作れる
